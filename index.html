Limites actuelles
  • L’index est conservé dans le navigateur de cet appareil. Exporter le JSON pour le sauvegarder ou le transférer vers un autre appareil.
  • Les PDF originaux ne sont pas copiés : garde-les dans iCloud Drive. Les résultats indiquent le numéro et la page mais l’ouverture directe du PDF sera ajoutée plus tard.
  • Les mots-clés sont des suggestions statistiques, pas une analyse IA. Les articles, thèmes et la synchronisation Notion ne sont pas encore intégrés.
  • PDF.js, Tesseract.js et le modèle OCR français sont chargés depuis Internet. Les pages sont traitées dans le navigateur.
  • Ne ferme pas l’onglet pendant le traitement. Fais régulièrement une sauvegarde JSON.
